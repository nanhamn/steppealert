# SteppeAlert
Пожары в Австралии: спутниковые данные NASA FIRMS об очагах огня + проверка вашего поля + уведомление в Telegram.

Запуск: `pip install -r requirements.txt && uvicorn main:app --reload`

Переменные окружения: `FIRMS_MAP_KEY` (бесплатный ключ NASA FIRMS), `TELEGRAM_BOT_TOKEN` (бот от @BotFather).
Без ключа сайт показывает демо-очаги.
